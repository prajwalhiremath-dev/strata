# strata Milestones 0–1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the `strata` repo and build a correct in-memory LSM core: internal key encoding, memtable, atomic write batches and a `Db` API. A model test checks it against `BTreeMap`. Both milestones come with learning chapters.

**Architecture:** A single Rust library crate.
- `key.rs` fixes the internal key format (`user_key ++ seqno<<8|kind`) that every later layer uses.
- `memtable.rs` is a `BTreeMap<InternalKey, Vec<u8>>` behind a `parking_lot::RwLock`.
- `db.rs` assigns sequence numbers under a write mutex, and publishes them with an atomic `visible_seqno` so batches appear all at once.
- There's no disk yet. The WAL and `Db::open(path)` arrive in milestone 2.

**Tech Stack:** Rust stable (edition 2024), `thiserror` 2, `parking_lot` 0.12, dev: `proptest` 1.

**Spec:** `docs/specs/2026-11-18-lsm-engine-design.md` (moves into the repo at `strata/docs/specs/` in Task 1)

## Review Focus

1. **Empty value vs missing key.** `put(k, b"")` then `get(k)` must return `Some(vec![])`, not `None`. Pinned in Task 5.
2. **A batch is never seen half-applied.** A reader running alongside a batch writer sees either none or all of the batch's keys. Pinned in Task 5 (concurrency test).
3. **Delete then re-put.** `put, delete, put` on the same key returns the last value. Delete of a missing key is a no-op success. Pinned in Task 5 and the model test.
4. **Key limits.** An empty key or a key longer than 65,535 bytes returns `Error::InvalidArgument` and nothing is written (the SSTable format in M3 stores key lengths as u16). Pinned in Task 5.
5. **Use after close.** Every operation after `close()` returns `Error::Closed`. `close()` twice is fine. Pinned in Task 5.

### Task 3: Internal key encoding

**Files:** Create `strata/src/key.rs`. Modify `strata/src/lib.rs` (`pub mod key;`).

**Interfaces:**
- Produces:
  - `pub type SeqNo = u64;` and `pub const MAX_SEQNO: SeqNo = (1 << 56) - 1;`
  - `#[repr(u8)] pub enum ValueKind { Delete = 0, Put = 1 }`
  - `pub struct InternalKey { pub user_key: Vec<u8>, pub seqno: SeqNo, pub kind: ValueKind }` with `Ord`: `user_key` asc, then `seqno` **desc**, then `kind` desc
  - `impl InternalKey { pub fn new(user_key: &[u8], seqno: SeqNo, kind: ValueKind) -> Self; pub fn encode(&self) -> Vec<u8>; pub fn decode(buf: &[u8]) -> Result<Self> }`
  - `pub fn compare_encoded(a: &[u8], b: &[u8]) -> std::cmp::Ordering` (used by SSTables in M3)
  - The encoding is `user_key` followed by an 8-byte **little-endian** `u64` trailer `(seqno << 8) | kind`.

- [ ] **Step 1: Failing tests** in `key.rs`:
  - `newer_seqno_sorts_first`: `InternalKey::new(b"a",5,Put) < InternalKey::new(b"a",3,Put)`

  - `roundtrip`: `decode(&k.encode()) == k` for `(b"key", 42, Delete)`

  - `decode_rejects_bad_kind`: a trailer with kind byte 7 gives `Err(Corruption)`
  - proptest `encoded_order_matches_struct_order`: for random `(Vec<u8> ≤8 bytes, seqno ≤ MAX_SEQNO, kind)` pairs, `compare_encoded(a.encode(), b.encode()) == a.cmp(&b)`

### Task 4: Memtable

**Files:** Create `strata/src/memtable.rs`. Modify `lib.rs` (`mod memtable;`, crate-private).

**Interfaces:**
- Consumes: `InternalKey`, `SeqNo`, `ValueKind` from Task 3.
- Produces:
  - `pub(crate) enum Lookup { Found(Vec<u8>), Deleted, NotFound }`
  - `pub(crate) struct Memtable` with:
    - `fn new() -> Self`
    - `fn insert(&self, seqno: SeqNo, kind: ValueKind, user_key: &[u8], value: &[u8])`
    - `fn get(&self, user_key: &[u8], snapshot: SeqNo) -> Lookup`
    - `fn scan(&self, start: Bound<&[u8]>, end: Bound<&[u8]>, snapshot: SeqNo) -> Vec<(Vec<u8>, Option<Vec<u8>>)>`: newest visible version per user key in range, `None` = tombstone, ascending
    - `fn approximate_size(&self) -> usize`: sum of key + value + 16 bytes overhead per entry

- [ ] **Step 1: Failing tests:**
  - `get_returns_newest_visible`: insert `(1,Put,"k","v1")` and `(2,Put,"k","v2")`. Then `get("k",2)` gives `Found("v2")`, `get("k",1)` gives `Found("v1")`, and `get("k",0)` gives `NotFound`.
  - `tombstone_hides_older_put`: `(1,Put,"k","v")`, `(2,Delete,"k","")`. Then `get("k",2)` gives `Deleted` and `get("k",1)` gives `Found("v")`.
  - `scan_newest_per_key_in_range`: keys a, b (put then delete), c, d. `scan(Included("a"), Excluded("d"), MAX)` gives `[("a",Some),("b",None),("c",Some)]`.
  - `size_grows`: `approximate_size` increases after an insert.
- [ ] **Step 2:** `cargo test memtable`. Expected: FAIL.
- [ ] **Step 3:** Implement with `RwLock<BTreeMap<InternalKey, Vec<u8>>>` + `AtomicUsize` size.
  - **Lookup:** `range(InternalKey::new(k, snapshot, Put)..)`. The first entry whose `user_key == k` is the answer.
  - **Scan:** map the bounds to internal keys. `(k, MAX_SEQNO, Put)` is the smallest internal key for `k`, and `(k, 0, Delete)` is the largest.
    - Included start → Included(smallest). Excluded start → Excluded(largest).
    - Included end → Included(largest). Excluded end → Excluded(smallest).
    - Skip entries with `seqno > snapshot`, and emit only the first entry per user key.
  - Add a test `scan_bound_kinds` covering all four bound combinations on keys a..e.
- [ ] **Step 4:** `cargo test memtable`. Expected: PASS.
- [ ] **Step 5:** Commit `feat(memtable): BTreeMap memtable with snapshot-aware get/scan`.
